# Archway Indonesia — Link Page

React + Vite + Tailwind + Framer Motion

## Stack
- React 18
- Vite 5
- Tailwind CSS 3
- Framer Motion 11
- React Icons 5

## Setup

### Install dependensi
```bash
npm install
```

### Jalankan dev server
```bash
npm run dev
```

### Build untuk production
```bash
npm run build
```
